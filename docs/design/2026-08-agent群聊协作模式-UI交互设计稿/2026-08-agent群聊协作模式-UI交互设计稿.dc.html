设计令牌与 signature element

signature element 是「权威轨 + 权威印记」：每条消息、每张项目卡左侧 3px 竖轨的线型表达权威等级，配合等宽小印记给出事实来源。去掉颜色后，线型与印记文字仍能区分身份与权威。其余界面保持克制：无渐变、无玻璃拟态、无拟人化装饰。

SIGNATURE · 权威轨线型
实线 — authoritative / confirmed fact（server ACK 或 stable event）
虚线 — proposal / pending acceptance（尚未成为事实）
点线 — local transient / preview（可丢弃，不入历史）
双线 — projection（由权威对象推导，如 Ball）
斜纹填充 — disputed / outcome_unknown（需人工闭合）
